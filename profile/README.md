# 🌱 Sprout DevLabs

Developer tools that make software projects easier to explore, understand, and build.

### [Sprout](https://github.com/Sprout-DevLabs/sprout): map your codebase, for you and your AI agent

A fast, single-binary directory explorer that respects `.gitignore`, shows git
changes and hotspots in the tree, renders a PR as a tree, and gives LLMs a
compact, token-budgeted project map. It also runs as an MCP server for coding
agents.

```bash
brew install sprout-devlabs/tap/sprout
sprout --ai | pbcopy
```
